# 🩺 CAPS Project - Sistema de Gestão de Pacientes com OCR

Este é um sistema desenvolvido como Trabalho de Conclusão de Curso (TCC) voltado para o **cadastro de pacientes**, **gerenciamento de documentos** e **processamento OCR de arquivos PDF**. O sistema é utilizado para digitalização, organização e automação de processos em Centros de Atenção Psicossocial (CAPS).

---

## 🛠️ Funcionalidades

- Cadastro, edição e exclusão de pacientes
- Armazenamento de documentos vinculados a pacientes
- Organização de atendimentos e processos
- Leitura e extração de texto de PDFs via OCR (Reconhecimento Óptico de Caracteres)
- Upload e download de arquivos
- Interface RESTful para integração com frontend ou sistemas externos

---

## 🚀 Tecnologias Utilizadas

- Java 17+
- Spring Boot
- Spring Data JPA + Hibernate
- Lombok
- MySQL 
- Tesseract OCR + OCRmyPDF
- Maven
- Swagger (para documentação da API)
